# 认知地图 · 具身导航 3D 实验

一个可离线运行的交互式 3D 演示，用来观察"认知地图"可能给机器人导航带来的差异。场景是一栋五层办公楼，同一套物理规则下，三种"地图里装了多少认知"的导航策略各跑一遍，比较它们遇到排队、半开的门、移动障碍、拥堵和门禁时的表现。

> 与其说是证明，不如说是一次探索。这是**网格仿真，不是真实机器人实测**；数字说明的是决策机制可能带来的差异，不代表真实场景的绝对速度或收益。

## 直接运行

双击打开 [index.html](index.html) 即可，**无需联网、无需安装任何依赖**——3D 绘图引擎和数据都已内嵌在单个 HTML 文件里。

## 它在演示什么

把导航拆成四个要素，看机器人在真实空间里如何把它们连成一张可执行的地图：

- **空间对象**：门、电梯、扶梯、走廊、房间，不只是几何体，而是带语义的对象；
- **动态状态**：客梯排队人数、清洁车位置、门的开合、走廊拥堵，这些会随时间变化；
- **动作可供性**：同一扇半开的门，对搬运者是障碍，对空手者是通道；上锁的门对有工牌者可通行；
- **长期记忆与共享**：机器人 A 踩过的坑，写进记忆后机器人 B 可以直接避开。

三种对照策略：

| 策略 | 拥有什么 | 表现 |
| --- | --- | --- |
| **几何导航 G**（红） | 只有 3D 静态地图，走几何最短路 | 无视排队、看不见移动障碍、不懂可供性 |
| **具身无记忆 E0** | 加入状态、可供性与时间维度，能等能绕 | 没见过的门一律假设能过 |
| **具身四层融合 E1** | 在 E0 基础上叠加长期记忆与多机器人共享 | 借用经验提前规避 |

## 七个场景

| # | 场景 | 看点 |
| --- | --- | --- |
| S1 | 午高峰 · 跨楼层配送（5F） | 状态层：读到客梯排队 16 人，改乘扶梯反而更快 |
| S2 | 移动清洁车 · 时间维度（3F） | 时间层：静态撞车失败，带时间维度可等待/绕行 |
| S3 / S3m | 半开的门 · 无记忆 / 有记忆（4F） | 记忆层：同样搬着货，无记忆撞门失败，有记忆提前绕行 |
| S4 | 多机器人 · 共享记忆（5F） | 经验复用：B 借用 A 的记忆，避开对方踩过的坑 |
| S5 | 能力对照 · 自己推门（4F） | 可供性：同一扇半开门，搬运者失败、空手者推开 |
| S6 | 门禁对照 · 刷卡通行（3F） | 能力：同一扇上锁门，无工牌失败、有工牌刷卡通过 |

面板上的秒数**不是预先写死的**：播放时随场景实时累计，机器人真正抵达那一刻才锁定，日志也只在那一刻记录"抵达"。

## 交互

- 左侧列表点击切换场景；底部按钮可 `播放/暂停`、`复位视角`、`区域划分`、`方块`显隐；
- 鼠标拖拽旋转、滚轮缩放，可缩放/旋转到任意楼层观察；
- 点击 `⟳ 随机客流` 会重新抽取排队人数、候梯时间、每层上下客、清洁车占位和门开启时刻，所有时间轴随之重算——同一场景每次跑出来的数字都不同。

## 参数口径

规格尽量参照国标设定：扶梯按 GB 16899-2011，30° 倾角、名义速度取常见的 0.5 米/秒，单层梯级运行约 18 秒；客梯按 GB/T 10058 速度系列取 1.75 米/秒，开关门各按 4 秒计，并计入途经楼层的停靠上下客。候梯时间随排队人数变化。

但需要说明：代价赋值与参数设定带有很强的主观性，换个设定结论未必相同，因此这个演示**不宜当作性能基准**。决策逻辑是规则写死的，并没有接入大模型。
